# 特性帧证据方法

验收契约见 [SKILL.md](../SKILL.md)。本文总结“证明新特性确实生效、且只作用于预期范围”的取证方法。
方法本身与具体特性无关；示例中的阈值、帧数和区域按任务定义。

## 总原则

- 按任务目标选择证据：行为中性改动走逐字节对拍；预期画面变化走作用域判定。
- 用 A/B 对照控制变量：只改一个参数，其他条件（场景、相机、光向、分辨率、帧号）保持一致。
- 差异要能解释：越界差异按回归处理，先查采集口径和共享状态，再改代码。
- 量化与目检互补：脚本回答“哪里变了、变多少”，裁剪放大图回答“变成什么样、对不对”。
- 阈值在采集前定：用理论值或基线零差作预期，避免事后给数字找解释。
- 证据可重跑：脚本、代表帧 PNG、分析 JSON 一起留在临时目录，回报带数字不带形容词。

## 方法族

### 1. 多帧稳态与动态相位对齐

静态稳态场景取连续多帧，检查组内哈希一致，确认画面已稳定；出现闪烁或异步加载时先核实稳定条件。
动画、输入等动态任务按锚定时钟与相位采集，跨组逐帧对齐并核对元数据。相邻帧不相同在动态场景中是
正常现象，判据是“同相位帧”而不是“同 seq 帧”。

### 2. 参数开关 A/B（生效性 + 作用域）

把新特性强度置 0 或开关关闭，同条件再采一组，全帧对比。判读两条：

1. 差异 bbox 落在特征作用域内；关断组与基线逐字节一致。
2. 差异计数大于 0 且形态符合特征；计数为 0 说明特性没有生效。

这是最常用的组合证据：一次对照同时回答“有没有生效”和“有没有误伤”。

### 3. 光向/输入摆动（行为依赖性）

依赖光向、视角或输入的特性，改变单一变量采两组：特征质心应随变量迁移，两组足迹重叠度递减。
量化用差异掩膜的质心坐标与位移量。两态只差一个受控变量，否则位移可能来自相机或场景混淆。

### 4. 裁剪放大对比（肉眼判读面）

全帧 PNG 裁剪特征区域并放大并排，命名体现分组，例如 `cmp_on_legs.png` / `cmp_off_legs.png`。
差异像素用二值掩膜着色叠加，绿色表示 A 组独有、品红表示 B 组独有。裁剪图用于判读
“出现/消失/形状/软硬边”，并作为回报的证据留存。

### 5. 差异量化指标

按特征选择指标，写进回报与 analysis JSON：

- 差异像素计数与 bbox：作用域判定；
- 掩膜质心与迁移量：方向响应；
- 游程长度众数：描边、高光带等带宽类特征；
- 色相/通道均值偏移：颜色类特征；
- 结构相似度或感知指标：只作参考项，不替代字节级门。

工具：计数/bbox/质心/游程用 `scripts/frame_diff_mask.py`；颜色统计按需写内联脚本并留档。

### 6. 强度回退安全网（跨路径等价）

新 shader 带强度混合系数时，强度 0 应与旧路径跨 shader 逐字节等价（稳态哈希相同）。
这是“新代码默认零行为”的位等价证明，也天然构成 A/B 对照的 B 组。
强度 0 等价不成立时，先查默认参数、分支条件和混合公式，再谈画面判读。

### 7. 双态判别面板（固化为回归资产）

一次性 A/B 取证可升级为固定判别场景：同一场景内双面板使用同 shader 同贴图，仅一个判别参数取两态。
基线入库后，特性存在性可以持续回归。适用条件：特性有单参数可观测态，场景能自包含闭包。
引擎级全局开关没有 per-run 覆盖机制时，先补基础设施，再固化判别场景。

### 8. 中性基线对照（重构/数据链类改动）

无观感变化的改动用历史基线或改前 control 对照：同条件帧哈希逐帧一致。基线条件要与历史 meta
（尺寸、视图、seq、场景）逐项核对；文档描述与实际场景漂移时，以 meta 为准修正。
没有历史基线时，改前先采 control，并在同一代码/构建状态重复采集确认基线可复现。
正式验证比较改前与改后版本；基线重复采集只证明采集稳定，不替代改前/改后对比。

## 伪证据反例

- **文件行序当解码序**：TGA 等格式的磁盘行序不等于解码后光栅行序；跨格式/跨链路对齐按解码器规范行序，
  取导入产物与源规范解码对照。
- **旧证据的巧合正确**：修掉缺陷 A 后，特性 B 引用的历史“正确”证据可能恰是 A 的另一形态。
  关联缺陷修复后，历史证据作废重取。
- **环境假失败**：端口被占、缓存指向旧场景、旧二进制未替换，都会制造整批假失败。
  先排除环境错误，再判读画面。
- **事后定阈值**：没有先验阈值的量化指标会变成“数字佐证叙事”。理论值（如游程 = 宽度 × 视口高度）
  在采集前算好。
- **只看差异不看范围**：差异存在不等于特性正确；差异必须落在作用域内，且关断组/基线保持零差。
