# 已知坑（图形迭代）

按症状查，按“症状 → 处置”阅读。修复状态以代码与模块文档为准；本册保留仍会影响判读的操作经验与适用条件。

## 出图与采集

- **近距/俯仰机位出图冻结（根因未定位）**：相机 z 越近越易触发，pitch 旋转同样触发；冻结帧跨会话逐字节相同，
  换探针材质也不更新。处置：判读机位保持足够距离，capture 后与上帧比哈希，同哈希时重试或挪机位，
  关键图用两个独立机位交叉。空帧先加距试剔，再排冻结。
- **采集输出目录需预创建**：否则日志与帧文件打开时报 FileNotFoundError。
- **哈希相同不等于冻结**：同相机静态内容下同哈希可能只是材质 rebake 落地窗，重试即可成功；
  跨预设/跨光向仍同哈希才是冻结签名。
- **探针判读三坑**：① 内容检测判据误匹配天空（`b-r>25` 命中蓝天渐变）——深色目标用纯暗判据
  （`r<130 ∧ g<130`），先在空探针基线上校零；② 阶梯采样后相机停在最后一档——选完档显式回移，
  再执行后续 capture；③ 采前核预设应用返回的 `frame` 锚与相机/灯四元数读回（d<1e-4）。
- **读图降到 1500–2000px 长边会丢细节**：1px 级纹理/小字先用 `--crop` 裁原生分辨率局部。
- **Windows 上 `os.kill(pid, 0)` 会直接杀进程**：会话存活判断走 `OpenProcess` + `GetExitCodeProcess`，
  复用现有会话客户端的内置实现。
- **编辑器退出可能回滚重导产物**：采帧会话退出后，部分重导产物与资产库时间戳文件可能被回滚；把这批产物
  视为会话内产物，入库状态以提交记录为准。

## 材质/资产热更边界

- **手改材质资源（含纹理槽换绑）后资产刷新只更新资产侧**：要让运行中场景看到新绑定，走材质写入的实时推送
  或场景重载。
- **live 材质写入探针遇材质源变更会静默失效**：源落盘触发实体重挂后，旧句柄上的后续写入无报错、画面保持旧值。
  自动判读与参数推送走“文件态 + 整会话轮”：改材质文件 → 刷新或重载会话验证。
- **资产刷新完成新资产入册**：落盘新资产 → 刷新（响应 `registered` ≥1 即入册，连刷归 0 幂等）→
  组件引用其 guid。无导入路由的源（预制体/时间线等）只入索引；修改预制体内容后重启会话重载。
- **shader 源内容变更在下次编辑器启动扫描时自动重导**：采帧前确认本次会话已含新变体。
- **clip 内容迭代用强制导入**：编辑器源时间戳判断可能把 clip 视为最新（刷新恒 changed:0），
  动画系统对 clipAsset 字段变更不敏感；强制重导后按产物路径分发事件并原位重建，直接 seek 即可。
- **应用预设后的组件读回可作快速判据**：首读四元数与预期逐分量 d<1e-4 即到位；200ms 轮询 3s 不收敛再判滞留。
  出图权威场合以批量出图响应中的 `frame` 锚定为准。
- **prefab 内骨节点与渲染器实体同名**：按名寻址命中不定，操作前用实体组件查询核验网格渲染组件在哪侧。
- **命令 schema 的 commands 是数组**：按条目 `name` 字段定位。

## 渲染/着色

- **bloom 参数打包序**：打包参数的 z/w 与 shader 消费位需要按契约对齐（z = 阈值 / w = 强度）。
  判读脚本的中性面把强度与阈值双归零，对打包序不敏感；参数重标定后重采对应基线。
- **近距头部机位角色整体消失/胸口镂空**：蒙皮剔除盒对已处缩放空间的顶点二次施加层级缩放，盒只剩部分几何；
  修复为逐骨变换包络。当前产物任意近距可拍；旧产物用较远的 detail 机位规避。
- **face 的 SDF 与 shadow map 分开使用**：face 自阴影由 SDF 面影承担，阴影衰减保持 1；
  hair 的 alpha-test 投影按当前实现记录。
- **阴影 bias 使用归一化深度**：大范围正交阴影下较大的 bias 会吃掉接触自阴影；
  按场景尺度标定并记录取值。
- **静帧哈希跨平台不可比**：基线 manifest 绑平台/后端，跨平台只比同口径统计量；本机自洽判据为
  稳态静态场景同窗多帧哈希收敛。

## 判读口径

- **只改场景描述文件对预设出图无效**：观察矩阵的工作点由 clip 键驱动（场景描述只等于 t=0 键）。
- **`--post neutral` 与 `--post scene` 的数字不同量纲**：bloom/描边会整体压暗或加暗线；同一轮只用同一 post 比较。
- **ROI 覆盖率会把描边暗线算进去**：后处理标定后旧覆盖率数字只作历史参考；单项覆盖数字作为观察项。
- **场景/预设数变了，ROI 与 contact sheet 口径先失效**：脚本的 WARN 作为核对提示。
- **效果验收以固定口径出图与人工判读为准**：golden 用于 agent 正确性与回归，见[判读与验收](03-evaluation.md)。

## 指标与搜索

- **clip seek 会覆写观察参数**：seek 会把 clip 键上的 exposure/ambient/灯位写回 Volume/Transform；
  参数设置在每次 seek 后重落，并在 capture 后复读，值不一致时整 trial 失败。
- **同参数两次 trial 的 sha 可能不同**：TAA 抖动、时钟相位、资产重导窗口都会影响非静态帧；搜索前先连跑
  两次基线比 sha，不同则重复评估取中位数。
- **score=0 是平原**：所有 leg 落窗后复合分恒 0，搜索没有梯度；改用有方向的 token 指标（如
  `paletteCoverageMin`）或在可行域内做第二轮次级目标。
- **缓存键只有参数**：`cache/<hash>.json` 不包含二进制/token/leg 集版本；换任一项就换 `cache_dir`。
- **材质写入会落盘**：trial 的材质补丁写材质文件，结束时写回原值；异常中断后核对 `git status`，
  按需还原。并发 trial 串行执行。
- **灯光 az/el 是传播方向**：正负号以实测为准；先在同一机位 A/B 两个角度确认换边/换向，再放进搜索。
- **色板覆盖率对阈值敏感**：阈值 5 时高光/阴影自然漂移就会大面积不命中；先看 p90 ΔE 与 `dominant_colors`，
  再调 `lookdev.paletteThreshold`。
- **saliency 在平画面/渐变背景上会贴边**：`bbox` 可能失真；看 `mass_frac`，构图判读优先用 `subject_bbox`（特写）。
- **Windows 写 JSON 带 BOM**：PowerShell `Set-Content -Encoding utf8` 会写 BOM；脚本按 `utf-8-sig` 读，
  手工排查时让其他工具也接受 BOM。

## 环境与工具

- **产物新鲜度**：判读前确认二进制构建时间晚于相关源码提交（用 `git log -S "<布点日志串>"` 定位特性落地提交；
  运行日志缺布点行说明二进制过旧），本机先重建编辑器。
- **macOS `sips` 两坑**：裸 BMP 读图链路不收；`sips --cropOffset 0 0` 退化为居中裁剪，非居中裁剪给非零偏移。
  新脚本走无损 PNG 转换。
- **采帧会触碰工程内材质资源的资产库元数据 hash 字段**（编辑器资产库行为），源内容不变；取证后按 `git status`
  还原，不计入迭代改动。
